# Documentation

This directory contains the project baseline for HumanArt. Start with [Architecture status](ARCHITECTURE-STATUS.md), then read [Architecture](architecture.md). The status record identifies the selected MVP decisions when earlier research material differs.

- [Architecture](architecture.md) is the current technical source of truth.
- [Architecture status](ARCHITECTURE-STATUS.md) records the canonical baseline and explicitly marks prior alternatives.
- [World integration](world-integration.md) defines the credential and authorization boundary.
- [Infrastructure and operations](infrastructure-and-operations.md) describes hosting, keys, and operational limits.
- [Development and validation](development-and-validation.md) defines milestones, test cases, and open decisions.
- [Hackathon material](hackathons/README.md) is event-specific and must not silently redefine the product architecture.
- [AI attribution](AI-ATTRIBUTION.md) records the assistance used to create and evolve the repository.

When implementation differs from these documents, update the relevant document in the same change and state whether the difference is a deliberate design revision or an implementation limitation.
